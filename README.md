# Getting Started

## 🚀 How to Run the Project

### 1. Clone the repository  
Clone this project into your desired folder, then open the project directory in your terminal.

### 2. Install dependencies  
Run the following command to install all required packages:

```bash
npm install
```

### 3. Start the development server  
Use this command to start the web app:

```bash
npm run dev
```

### 4. Open the app  
After running the command above, Vite will provide a **localhost link**.  
Open it in your browser to preview the **ExpenseTracker** app.
